# TSMapTool — менеджер мультиплеєрних карт TimeShift (PC)

Інструмент додає, переглядає, експортує та видаляє мультиплеєрні карти PC-версії TimeShift.
Карти можна брати з Xbox 360 DLC-пакетів (файли з Xbox Live з довгими іменами на кшталт
`2F61D2EC…`) або з файлів `.tsmap`, які створює сам інструмент.

Потрібен Python 3 (перевірено на 3.14). Сторонні бібліотеки не потрібні.

## Запуск

- **Графічний інтерфейс:** `TSMapTool.bat` (або подвійний клік на `maptool_gui.pyw`).
- **Командний рядок:** `python maptool.py <команда>`.

Папка гри визначається автоматично (інструмент лежить у ній). Інакше її можна вказати
кнопкою «Змінити…» або параметром `--game "D:\Games\TimeShift"`. Вибір запам'ятовується в `config.json`.

Перед змінами закрийте гру.

## Що вміє

| Дія | GUI | Командний рядок |
|---|---|---|
| Список карт | головне вікно | `maptool.py list` |
| Подробиці, опис, превʼю | вибрати карту | `maptool.py info <рівень> [--preview файл.png]` |
| Імпорт Xbox DLC-пакета або `.tsmap` | «Імпорт файлу…» | `maptool.py import <файл> [...] [--maps a,b]` |
| Імпорт розпакованої Xbox-папки | «Імпорт папки…» | `maptool.py import <папка>` |
| Експорт карти в `.tsmap` | «Експорт…» | `maptool.py export <рівень> <файл.tsmap>` |
| Видалити додану карту | «Видалити / приховати» | `maptool.py remove <рівень>` |
| Приховати оригінальну карту з меню | «Видалити / приховати» | `maptool.py remove <рівень>` |
| Повернути приховану карту | «Повернути приховану» | `maptool.py unhide <рівень>` |
| Перезібрати архіви гри | «Застосувати» | `maptool.py apply` |
| Повернути оригінальні архіви | «Відновити оригінал гри» | `maptool.py restore` |
| Перевірити архіви гри | — | `maptool.py verify` |

`<рівень>` — внутрішнє ім'я карти, наприклад `dlc1_multiplayer13` чи `multiplayer2` (колонка «Рівень»).
Імпорт, видалення та повернення одразу застосовуються до гри (у CLI це можна вимкнути `--no-apply`).

## Як це працює

- **Бекап.** Оригінальні архіви лежать у `preload\paks_backup_original\`. Якщо цієї папки немає,
  інструмент створить її сам, але лише якщо поточні архіви ще оригінальні.
- **Бібліотека.** Кожна додана карта зберігається як окремий файл `library\<рівень>.tsmap`.
  Список карт, їхні id і приховані карти записані в `library\library.json`.
- **Застосування.** `patch.s3darc`, `patch_nv.s3darc` і `patch_ati.s3darc` щоразу збираються заново:
  оригінали з бекапу плюс усі карти бібліотеки. Видалена карта не лишає слідів. «Відновити оригінал»
  просто копіює файли з бекапу, бібліотека при цьому зберігається. `out*.s3darc` ніколи не змінюються.
- **Порядок запису.** Нові архіви спершу записуються у `*.tmp` і перевіряються (CRC кожного запису),
  а вже потім замінюють робочі.

При імпорті з Xbox карта конвертується в PC-формат:

- **Що береться з пакета.** Лише ресурси, яких немає в PC-грі: геометрія `.lg`, колізія `.cdt`/`.sm`,
  трава `.grs`, дощ `.rain`, траси `.trc`, лайтмапи, нові текстури та завантажувальні екрани.
  Решту ресурсів карта бере з PC-версії.
- **Текстури.** У заголовку `TCIP` абсолютні Xbox-зміщення замінюються на `0xFFFFFFFF`, як у PC-архівах.
  Пікселі не змінюються.
- **Карти нормалей і маски (3Dc/BC5, BC4).** Для ATI вони беруться як є, для NVIDIA перекодовуються
  в DXT5/DXT1 так само, як в оригінальних PC-архівах.
- **Список передзавантаження.** Переводиться в PC-формат. Посилання на Xbox-ресурси, яких на PC немає
  (іконки, кнопки геймпада), прибираються. Замість Xbox-шейдерів використовуються шейдерні пари
  оригінальних PC-карт.
- **Запис у меню.** Додається в `gs_map_list` разом із назвою й описом для 9 мов гри. Мови, яких
  немає в DLC, отримують англійський текст.
- **id карт.** Видаються з вільного діапазону 15–29 (там, де в оригінальному коді були службові
  заглушки DLC).

## Гра по мережі

У всіх гравців мають бути ті самі карти з тими самими id. Найпростіше передати друзям три файли
`preload\paks\patch.s3darc`, `patch_nv.s3darc`, `patch_ati.s3darc`. Інший варіант — передати
`.tsmap`, але тоді їх треба імпортувати в тому самому порядку.

## Формат .tsmap

ZIP-архів:

- `manifest.json` містить такі поля:
  - `class` — ім'я рівня;
  - `title` — назва;
  - `source` — звідки карта;
  - `entry` — властивості карти для `gs_map_list` без `id`: режими, кількість гравців, `LoadingTexture` тощо;
  - `strings` — рядки локалізації за мовами;
  - `loading` — текстура завантажувального екрана;
  - `files` — список файлів (ім'я, тип запису архіву, архів `main`/`nv`/`ati`/`all`).
- `files/NNN.bin` — дані записів у тому вигляді, у якому вони лягають в архів гри (без стиснення zlib).

Експорт оригінальної карти дає `.tsmap` з її рівнем, лайтмапами, списком передзавантаження та
завантажувальним екраном. Спільні ресурси гри в нього не входять.

## Обмеження

- Підтримуються лише STFS-пакети з нефрагментованими файлами. Офіційні DLC TimeShift саме такі.
- Карту з ім'ям рівня, яке вже є в грі, імпортувати не можна.
- id понад 29 видаються лише коли діапазон 15–29 вичерпано. Такі id у грі не перевірялися.
- Змінювати можна тільки мультиплеєрні карти.

## Структура

```
TSMapTool\
  TSMapTool.bat        запуск GUI
  maptool_gui.pyw      графічний інтерфейс
  maptool.py           командний рядок
  tsmap\s3darc.py      читання / запис архівів .s3darc
  tsmap\xbox.py        Xbox 360 STFS, .s3dpak/.s3dlst, текстури
  tsmap\core.py        бібліотека карт, імпорт / експорт, збирання архівів
  library\             бібліотека доданих карт (*.tsmap, library.json)
```
